# Security Policy

## Supported Scope

This repository contains deployment templates, runbooks, and automation wrappers for the Guest Permissions solution package.

## Reporting a Vulnerability

If you discover a security issue in this repo:

1. Do not open a public issue with exploit details.
2. Report privately to the repository maintainers through your internal security process.
3. Include reproduction steps, affected files, and impact assessment.

## Security Expectations for Contributions

- Do not commit secrets (keys, tokens, connection strings).
- Use managed identity where possible.
- Keep permission scopes least-privilege and documented.
- Separate infrastructure deployment from privileged grant operations.
